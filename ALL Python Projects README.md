#            ~ 1996-2023 College Scorecard Exploratory Data Analysis  ~

**Introduction: A dive into utilizing visualizations to present a more intuitive understanding of the College Scorecard data. As compared 
to simply viewing raw SQL query results or tabular data as an analyst through intricate features, in detail distributions, 
and values at points throughout the plots. While a SQL query can return raw data in it’s simplest format or aggregate 
statistics, line charts, bar charts and histograms immediately highlight trends, outliers and the relative differences 
in the variables data; Seeing if rates are clustered around a certain value, extreme point(very selective or open admission), or if the data is skewed**

*Data Source: U.S. Department of Education. (2025). College Scorecard - Download the Data. https://collegescorecard.ed.gov/data/  
(the direct csv file is too large to upload)*

*Glossary: https://collegescorecard.ed.gov/data/glossary/*

 #                   ~ Colorectal Cancer Screening Survey ~

 **Introduction: Colorectal cancer rates are increasing among young adults, alongside not currently being routinely screened. 
 Previous studies have implemented methods to increase screening rates, and recent research shows that there may be warning signs for colorectal cancer 
 amongst young adults.**
 **Why ?: To create a screening tool that can be disseminated to younger adults to help increase the early detection of colorectal 
 cancer and promote screening efforts. More specifically, takes patient data and returns a screening recommendation based on a patient’s self-reported 
 risk factors and symptoms.**

 *Data Source: Python Faker package for a synthetic patient dataset*
